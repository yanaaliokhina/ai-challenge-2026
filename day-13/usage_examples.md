# Day 13 – Usage Examples

## How to Run

> **Note:** The `index.json` file used below can be generated by running the Day 12 challenge (`day-12`), which builds and persists an embedding index to disk.

Search an index with a query (default top 3 results):
```bash
python src/main.py --index data/index.json --query "What is machine learning?"
```

Return top 5 results:
```bash
python src/main.py --index data/index.json --query "neural networks and deep learning" --top 5
```

Use a specific embedding model:
```bash
python src/main.py --index data/index.json --query "How do transformers work?" --model text-embedding-3-large
```

### Expected Output

```
Query: "What is machine learning?"
Index: data/index.json (42 entries)

Results:
1. [score: 0.9312] id=chunk_003
   Machine learning is a subset of AI that enables systems to learn from data...

2. [score: 0.8741] id=chunk_017
   Supervised learning algorithms learn patterns from labeled training examples...

3. [score: 0.8205] id=chunk_009
   Feature engineering transforms raw data into representations suitable for ML models...
```

### Error Cases

Missing index file:
```bash
python src/main.py --index missing.json --query "test"
# Error: Index file not found: missing.json
```

Empty query:
```bash
python src/main.py --index data/index.json --query ""
# Error: Query must not be empty
```

## How to Run Tests

Run all tests:
```bash
pytest tests/ -v
```

Run only the similarity search tests:
```bash
pytest tests/test_search.py -v
```

Run only the CLI argument tests:
```bash
pytest tests/test_cli.py -v
```

Run tests without hitting the real embedding API (uses mocked embeddings):
```bash
pytest tests/ -v -m "not integration"
```

Run integration tests (requires valid `OPENAI_API_KEY`):
```bash
pytest tests/ -v -m integration
```
